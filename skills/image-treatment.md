# Images and editable explanation
Choose visuals to serve the argument, not an image quota.
- Use editable SVG for diagrams, relationships, processes and illustrations; use LaTeX for formulas. Do not rasterize text, math or data merely for convenience.
- Use photography or generated illustration when appropriate. Image generation must already be manually enabled; never change the opt-in through agent tools.
- Specify subject, viewpoint, palette, light, negative space and intended crop. Save assets locally.
- Preserve aspect ratio. Use contain when the whole object matters and cover for deliberate cropping.
- Inspect focal points, captions, edge alignment and text contrast over images. Masks and overlays should improve hierarchy.
- Capture the actual page after insertion and adjust x/y/w/h or object-position precisely. Missing cross-origin images are limitations to report, not successful visual verification.
