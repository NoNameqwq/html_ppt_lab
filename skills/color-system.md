# 配色与主题

## 优先使用主题变量
- 背景 `--wpx-bg`，主文字 `--wpx-fg`，次级文字 `--wpx-fg-2`，弱化 `--wpx-muted`。
- 强调 `--wpx-accent` / `--wpx-accent-2`，分隔线 `--wpx-line`，圆角 `--wpx-radius`。
- 新元素颜色写 `var(--wpx-*)`，不要写死十六进制；确需固定色再用具体值。换主题后硬编码颜色会“脱节”。

## 60-30-10
- 60% 背景色，30% 文字/图片明暗，10% 强调色。
- 强调色一页最多出现 1–2 处（关键词、数字、细线），覆盖面积不超过 5%。
- 强调色不用于大块背景（封面/收尾页除外），同页不要同时用两种强调色。

## 对比度
- 正文与背景对比 ≥ 4.5:1，大标题 ≥ 3:1。深色底用 #F2EAE0 骨白而非纯白，浅色底用 #1B1A17 墨黑而非纯黑。
- 半透明文字最低 60% 不透明度，且只用于注释。
- 图片上压字：先加暗色/亮色渐变遮罩（linear-gradient），再放文字；不要只靠阴影。

## 派生色
- 用 `color-mix(in srgb,var(--wpx-accent) 12%,transparent)` 做浅底/悬停；`opacity` 会连带图片一起透明，优先用 color-mix。
- 深色主题里强调色浅底降到 10–14%，否则发灰。

## 主题风格速查
ink 墨黑+骨白+朱砂（文化感、强对比）；paper 米白+墨黑（刊物感）；bloom 深紫+粉+奶油（时尚柔和）；
celadon 青瓷（清雅东方）；midnight 午夜蓝（科技冷静）；vermilion 朱砂（热烈、单一强调）；mono 黑白（极简）；editorial 报刊（理性多栏）。

## 检查
- 同页出现 ≥3 种有彩色即报警，回到 1–2 种。
- 换主题后用 `deck_get_state` 核对页背景与元素颜色是否仍协调。
- 需要全局换色时优先 `deck_set_theme`（theme id 或 vars），不要逐元素改色。
