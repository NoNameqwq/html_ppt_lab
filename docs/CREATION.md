# 页面知识表达、结构导航与生图

公式与 SVG 的目标是演示页面本身。`deck_compose` 支持 `math` 和 `svg` 元素；HTML / 文本中的 `$…$`、`$$…$$`、`\(…\)`、`\[…\]` 也会在写入画布前排版。KaTeX 结果与原始 LaTeX 一同保存；SVG 保留源码。保存、版本、放映和离线 HTML 导出沿用同一内容，不依赖在线数学渲染服务。动态脚本生成的内容应由脚本自己调用渲染或改用这些原生工具。

## 结构与目录

内置技能分为内容与设计目录，支持递归发现，原有 ID 保持兼容。新会话默认启用「Deck 代码规范」「演示叙事」「动效设计」；其他技能可在「设计技能」里按需启用，旧会话保留自己的技能开关。

- [Frontend Slides](https://github.com/zarazhangrui/frontend-slides)：固定舞台、演讲 / 阅读密度、视觉母题。MIT，已用英文改写适配。
- [Anthropic PPTX](https://github.com/anthropics/skills/tree/main/skills/pptx)：图文构图、布局变化、对齐和视觉检查。Apache-2.0，已用英文改写适配。
- `structured-navigation`：本项目的章节组织、页面预算和动画目录规则。

系统设计提示词、创作指南、三角色协作指令及 10 个内置技能正文统一使用英文；技能名称、界面和最终作品语言仍按用户需求。版式、字体、配色与动效建议是起点，可按内容调整。

目录是否需要、采用什么结构与动画由内容决定，计入用户指定总页数。6 页以上的创作简报提供可选的导航决策位置，也可换成内容页。目录可在 `deck_compose.slides[i].navigation` 声明，或通过 `deck_set_navigation` 替换一页；「插入 → 动画目录」仍提供快速预设。

Agent 可以使用 `style:"custom"` 配合任意 HTML / SVG / CSS 设计 2–24 个章节的原创目录，不限于内置花瓣、轨道、阶梯。自定义 HTML 每个章节 i 的点击节点需同时带有 `data-wds-target="{{target:i}}"` 和 `data-wpx-action="go-id:{{target:i}}"`，工具将 token 绑定为稳定页面 ID。交互脚本与自定义页面转场可通过工程代码工具实现。下一级目录需有足够内容与页数预算。

章节以页面 ID 绑定，移动页面后链接不变；删除目标后需要更新目录。预设目录支持进入展开与选中图形放大；原创目录使用自身 CSS 动画与目标页转场，可自行设计其他形式，并应遵循减少动态效果设置。内置「知识花园」8 页模板可直接新建体验，源码可通过 `node scripts/build-knowledge-template.mjs` 重建。

## 多模态查看与精调

选择支持图片输入的对话模型后，Agent 可以调用 `deck_capture_slide` 查看当前工程画面，包含尚未保存的编辑。支持指定页码、元素 ID 或逻辑坐标区域，并返回 PNG、元素位置、字号、字体及越界信息。工具结果中的图片真正送入下一次模型请求，也会随对话保存，可展开操作记录查看。

指令要求按「截图观察 → 读取元素与坐标 → 局部调整 → 再截图复核」工作。文字模型不下发截图工具，也不会收到截图图片。在极高思考的三角色模式中，设计和检查角色建议选择支持图片的模型；支持图片的检查角色须先尝试截图再通过验收，截图失败需说明限制。

截图使用编辑器 DOM 渲染，坐标为 1920 × 1080 页面单位，包含内置 Three.js 的 WebGL 画面；跨域图片缺少 CORS 时可能省略，视频、第三方 WebGL、部分滤镜及浏览器合成效果需要另行验证。3D 鼠标和触摸交互需单独测试。实际模型能否理解图片取决于所配服务及模型能力；仅填写任意模型 ID 不代表支持多模态。

## 生图（默认关闭）

Agent「+ → 生图设置」填写独立的服务地址、模型 ID、API Key，手动勾选允许并保存。取消不会启用。关闭后保留已有图片，但禁止新的生成。模型不能通过通用设置 API 开启此开关。

兼容 OpenAI Images 的 `POST /images/generations`，服务地址可填 Base URL 或完整端点。必要参数为 `model`、`prompt`、`n:1`，默认省略可选的尺寸、质量与返回格式；支持 `data[0].b64_json` 和直接下载的 `data[0].url`。GPT Image 服务使用默认返回格式；其他兼容服务可按需指定 Base64 / URL。每个服务商支持的尺寸与质量可能不同。

官方接口参数参考：[OpenAI SDK 中由 OpenAPI 生成的定义](https://github.com/openai/openai-python/blob/main/src/openai/types/image_generate_params.py)。本次官方文档网页访问返回 403，因此依据这一官方源文件核对必要字段；没有使用第三方博客推断参数。

`deck_generate_image` 生成图片并自动插入指定页面；`images.generate` API 仅生成工程素材。图片保存为 `assets/generated-*.png|jpg|webp|gif`，进入工程版本并随 HTML 导出。密钥仅保存在服务端，不进入公开设置或对话提示。支持停止请求、3 分钟超时、大小限制、格式检查与失败提示；失败不伪造素材或完成状态。

## 右键重做

元素与整页的 AI 重做都先打开要求窗口，可补充风格、内容、布局与动效要求，默认保留内容与含义。取消不会发送；确认后才发送给 Agent。对话生成中遵循既有排队机制。工程或页序改变时要求重新选择目标。

## 艺术字

插入 → 艺术字（或元素右键「转成艺术字」）打开工坊，生成的是**一个可再编辑元素**，不是截图或位图。实现分三块：

- `app/js/core/type-kit.js`：无 DOM 依赖的生成器与预设目录。静态效果（渐变填充、描边、多层阴影、纹理）全部落到元素自带 `<style>`；动画用带随机 token 的关键帧名，避免同页多个作品互相覆盖。
- `app/js/core/stroke-data.js` + `/api/hanzi`：按字符取笔顺数据。服务端把打包文件解码一次并缓存，只为请求的字返回路径；笔画按 1024 网格、y 轴向上，渲染时 `translate(0,900) scale(1,-1)`。
- `editor/type-runtime.js`：切页时给作品加 `.wtk-play`。它只看页容器的结构和激活类，不看瞬时透明度——过渡动画期间透明度会瞬间为 0，用透明度判断会让作品永久停在首帧。脚本缺失时 CSS 的暂停规则不生效，动画照常播放，不会出现空白页。

编辑态动画：`deck-runtime.css` 与 `deck-runtime.js` 的「编辑态动画压到终态」规则排除了 `[data-wds-type]` 及其子树，作品在编辑时按真实节奏播放，便于直接看效果。

导出：能内联的作品全部内联；仅当页面确实含作品时才保留 `type-runtime`，静态单文件版不打包 40MB 笔画库，笔画预设在其上自动退化为普通文字并在结果中说明。

验证：`npm run qa:type`（隔离数据 + 真实 Chrome）覆盖取数、渲染像素、动画启停与重播、部首高亮、导出自包含、离线打开与静态版降级。

## 验证

`npm run test:authoring` 覆盖页面排版、导航预算、生图开关与失败路径；`npm run qa:authoring` 使用隔离数据与本地模型验证页内公式、SVG、目录、右键要求、手动配置生图、自动入页、版本与放映。生图集成使用本地模拟服务验证，不消耗真实模型额度。
