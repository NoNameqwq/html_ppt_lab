# 3D 结构与并行生成

在 Agent 中描述要构建的 3D 结构，例如「构建可以旋转观察的分子结构，旁边用 LaTeX 解释键角」，或使用「插入 → 3D 结构」。可用场景 JSON 修改几何、材质、灯光和相机；高级 Three.js 代码支持程序化结构与动画。

## 操控与编辑

- 编辑时点击组件内「操控 3D」，再拖动模型；点击「完成 3D」或按 Escape 恢复页面元素编辑。
- 鼠标左键拖动旋转，滚轮缩放，右键拖动平移。
- 触摸单指旋转，双指缩放和移动；「复位」恢复初始视角。
- 放映时直接操控组件，组件内手势不会触发工作台翻页。组件外保留放映交互。
- 文本、说明、SVG 和 LaTeX 可独立排在 3D 旁边，继续使用编辑器的选择、布局和撤销。

Three.js 0.181.1 与 OrbitControls 已内置，无需 CDN。使用 3D 的网页导出包含引擎、操控器、运行时和场景源码；未使用 3D 的演示导出不包含引擎。后端模式、静态单文件工作台、版本交付及原稿插入补丁均支持。再次导入导出的网页可继续编辑。

渲染需要浏览器支持 WebGL 2；不支持时组件显示实际错误，保留场景源码。自行引用的远程模型、纹理和网络资源仍受原地址与 CORS 限制；需要离线交付时使用工程素材或程序化几何。内置引擎与场景本身不依赖网络。

编辑桥会在打开工程和插入内容时检查 3D 运行时，旧 BAT 服务漏注入初始化脚本时自动补载；加载失败显示错误与重试入口。状态检查与多模态截图等待首次引擎加载结束，避免只截到底色。自定义代码设置的相机和观察中心不会被自动取景覆盖。

## Agent 并行制作

明确要求制作 3D 时，Agent 先通过 `agent_parallel` 后台派发 2–4 个独立任务，可拆分几何、视觉与交互、独立核查等工作；职责和接口由主代理确定。派发立即返回，主模型同时继续处理独立页面、布局和关键代码。需要整合时通过 `agent_wait` 等待所需批次或指定任务，也可用 `agent_parallel_status` 查看进度与完整输出。最终检查与交付前必须收齐结果并验收实际工程，提前结束会自动等待结果后继续整合。

- 普通思考：所有子任务使用当前对话模型和服务。
- 极高思考：任务按 design / implement / review 角色使用「API 设置 → 子代理协作」中的模型。
- 已有的三角色协作也能派发并行任务；依赖前一步结果的整合、最终检查仍按顺序执行。

子代理并行返回代码或数据，使用只读工具查看当前工程。主代理统一应用修改并建立版本，随后验收实际结果。界面显示各子任务的模型、状态和完整输出。停止会取消未完成请求，继续时复用已完成任务，只恢复未完成部分。

SVG 精细绘图也支持同一后台机制。明确制作或重绘 SVG 时，会派发独立绘图与核查工作；单独改标签、颜色、字号或位置无需启动并行。任务可设置 `artifact:"svg"|"three"|"analysis"`，`sharedContext` 统一传递 viewBox / 单位、部件边界、连接锚点、ID 前缀、图层顺序、字体、配色与验收标准。SVG 绘图代理必须交付完整源码；仅提纲或残缺 XML 会被要求补全，连续失败则保留输出并报告未完成。普通思考仍使用当前模型，极高使用配置的角色模型，主模型继续独立工作。

绘图指导使用英文，在 SVG / 图解和 3D 任务及对应子代理中自动加载。SVG 包含详细的构图、语义分层、精确几何、部件与剖面细节、科学曲线、标注避让、局部放大、描边/材质处理、可用 SVG 元素、完整交付和放大检查流程。Three.js 强调真实部件结构与连接、程序化几何、材质灯光、相机、性能和多角度验收。`SVG 精细图解` 技能还可手动开启。结构校验只证明源码完整；模型需在实际插入后使用多模态查看画面并细调，不能将 XML 合法或 Canvas 就绪等同于绘制质量。

## 工具与源码

`deck_insert_3d {scene?,code?,label?,elementId?,index?,x?,y?,w?,h?}` 插入或更新组件；`deck_compose` 支持 `type:"three"` 的元素，沿用同一场景格式。声明式场景允许可编辑权限，自定义代码需要完全访问。`deck_get_3d_state` 返回实际渲染就绪状态、错误、相机和交互状态。

场景支持嵌套对象、几何、材质、光源、相机和 OrbitControls 参数；完整契约见 `skills/code/three-dimension.md`。自定义 factory 接收 `THREE, scene, camera, renderer, controls, host, root`，向 root / scene 添加对象，可返回 `update(timeSeconds,deltaSeconds)` 和 `dispose()`。运行时负责绘制、尺寸更新和 GPU 资源释放。

页面中只持久化场景 JSON 和代码，运行时重建 Canvas。保存、撤销和版本恢复不会保留旧 GPU 对象。缩略图使用静态快照；多模态截图包含内置 Three.js 的实际像素及渲染状态，仍需单独测试交互和动画。
